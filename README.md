# BOOK NEXUS — 로컬 전자책 서재

구매처가 다른 전자책을 한눈에 살펴보는 통합 서재입니다. Next.js, TypeScript, Tailwind CSS로 만들었습니다.

Android·iOS용 별도 네이티브 앱 소스는 [`mobile/`](./mobile/README.md)에 있습니다. PC 웹 버전과 책 파일·계정은 자동 동기화되지 않습니다.

## 현재 구현 범위

- 반응형 한국어 통합 서재 첫 화면
- BOOK NEXUS 로컬 개발용 회원가입·로그인·로그아웃 (이메일과 비밀번호)
- 로그인한 계정 ID별 브라우저 서재 분리, 기존 익명 서재의 명시적 복사 기능
- 리디·알라딘·YES24·교보문고·밀리의 서재·북큐브 공식 사이트 바로가기와 서점별 직접 등록 안내
- 실재하는 전자책 6권의 서점별 공식 상품 페이지 바로가기와 구매처 배지 (구매 내역은 아님)
- 서점 전자책 상품 링크만 직접 등록·삭제 (구매 사실 인증 없음)
- 구매처별 필터 및 제목·저자·분야·구매처 검색
- 내 DRM 없는 EPUB/PDF 파일 직접 등록 (100MB 이하)
- 파일 등록 시 구매처 및 공식 상품 주소 직접 지정, EPUB/PDF 내장 리더
- EPUB 읽은 위치(CFI), PDF 현재 페이지, 진행률, 책갈피를 브라우저 IndexedDB에 저장
- 저장한 책과 기록 삭제, 빈 검색 결과 안내
- 배포 버전의 화면·정적 파일 오프라인 캐시 (처음 온라인 방문 후 활성화)
- 모바일, 태블릿, 데스크톱 레이아웃

## 아직 구현하지 않은 기능

- 실제 서점 계정 연동 또는 구매 내역 가져오기
- DRM 전자책 열람
- 계정 간 파일·기록 동기화
- 이메일 주소 확인·비밀번호 재설정·클라우드 배포용 계정 운영

BOOK NEXUS 계정은 이 컴퓨터의 `data/auth.sqlite`에 저장됩니다. 책 링크·파일·독서 기록은 로그인한 계정별로 **현재 브라우저의 IndexedDB**에 따로 저장되며 서버나 다른 기기로 동기화되지 않습니다. 같은 컴퓨터의 브라우저 데이터에 접근할 수 있는 사람을 막는 암호화 저장소는 아닙니다. 시크릿 창이나 브라우저 데이터 삭제 시 책과 기록이 사라질 수 있습니다. 서점 선택과 상품 주소는 구매 사실 확인이 아닙니다. 외부 상품 페이지는 인터넷 연결이 필요합니다.

BOOK NEXUS 회원가입은 각 서점 회원가입과 무관합니다. 이용자가 동의하더라도 해당 서점이 외부 서비스에 구매목록 접근 권한을 제공하지 않으면 결제·보유 도서를 자동으로 가져올 수 없습니다. 현재 여섯 서점 연결은 공식 사이트를 여는 바로가기이며 구매 내역을 가져오지 않습니다. **서점 아이디·비밀번호를 BOOK NEXUS에 입력하지 마세요.**

## 명령어 없이 사용하기 (Windows 11)

1. 파일 탐색기에서 이 폴더의 `start-book-nexus.cmd`를 더블클릭합니다. 첫 실행이나 소스 변경 후에는 준비 작업에 시간이 걸릴 수 있습니다.
2. 열린 창에 `Ready`가 표시되면 `BOOK-NEXUS-OPEN.url`을 더블클릭합니다. 기본 브라우저에서 `http://localhost:3021`이 열립니다.
3. BOOK NEXUS를 쓰는 동안 시작 창은 열어 두세요. 사용을 마치면 창에서 `Ctrl+C`를 누르거나 창을 닫으면 됩니다. 다음번에는 시작 파일을 다시 더블클릭하면 됩니다.

Node.js 24 이상은 설치되어 있어야 합니다. `3021` 포트가 이미 사용 중이면 시작 파일이 기존 서버를 덮어쓰지 않고 안내 메시지를 표시합니다. 다른 컴퓨터에서 접속되는 공개 웹사이트가 아니며, PC가 꺼져 있으면 접속할 수 없습니다. 계정은 로컬 개발용이므로 공개 배포에는 별도의 보안·데이터 저장 설계가 필요합니다.

## Windows 11 PowerShell에서 실행하기 (개발자용)

VS Code에서 이 폴더를 열거나 PowerShell에서 다음을 실행합니다.

```powershell
Set-Location "C:\Users\Administrator\Documents\Codex\2026-10-22\referenced-chatgpt-conversation-this-is-an\outputs\book-nexus"
npm.cmd ci --legacy-peer-deps
npm.cmd run dev
```

Node.js 24 이상이 필요합니다. 첫 실행 시 로컬 로그인용 비밀 키를 `.env.local`에 자동 생성하고 계정 데이터 디렉터리 `data/`를 만듭니다. 두 파일/폴더는 Git에 포함하지 마세요. 계정은 개발용이며 이메일 인증·비밀번호 복구가 없어 공개 서버에 그대로 배포하면 안 됩니다. 계정 파일을 삭제하면 기존 계정으로 로그인할 수 없으므로 백업이 필요합니다.
`npm.cmd run build`는 이 Windows 환경에서 검증한 Next.js 기본 빌드를 사용합니다. 빌드 전에는 실행 중인 BOOK NEXUS 서버를 종료하세요.

개발 서버는 브라우저에서 `http://localhost:3000`을 엽니다. 직접 등록한 책은 주소와 포트별로 따로 저장됩니다. 현재 사용자용 화면과 `start-book-nexus.cmd`는 **`http://localhost:3021`**을 사용하므로, 계속 같은 서재를 쓰려면 해당 주소로 여세요. 이전에 3014번이나 3020번에서 등록한 책은 3021번의 브라우저 저장소에 자동으로 나타나지 않습니다.
PowerShell의 스크립트 실행 정책 때문에 `npm`이 차단되면 위와 같이 `npm.cmd`를 사용하세요. 명령 프롬프트에서도 같은 `npm.cmd` 명령을 사용할 수 있습니다. `start-book-nexus.cmd`는 올바른 폴더에서 최신 버전을 빌드한 다음 사이트를 실행합니다. 코드 수정 사항을 바로 보려면 위의 `npm.cmd run dev`를 사용하세요.

## 로그인하고 내 서재 사용하기

1. 홈의 `회원가입`에서 BOOK NEXUS 계정을 만듭니다. 리디 계정과 별개이므로 다른 비밀번호를 사용하세요.
2. 로그인한 뒤 파일 또는 공식 서점 상품 링크를 등록합니다. 로그인 전에는 예시 도서만 보입니다.
3. 이전 버전에서 이 브라우저에 저장했던 책이 있다면, 로그인 후 `기존 서재 가져오기`를 눌러 현재 계정의 로컬 서재로 **복사**합니다. 원본은 자동 삭제하지 않습니다. 공유 컴퓨터라면 다른 사람의 로컬 책이 포함될 수 있으므로 내용을 확인한 뒤 진행하세요.
4. 로그아웃하면 내 책은 화면에서 숨겨집니다. 다른 BOOK NEXUS 계정으로 로그인하면 별도의 로컬 서재가 열립니다.

이 기능은 같은 브라우저 안에서 데이터가 우연히 섞이지 않게 구분할 뿐, 브라우저 저장 파일을 암호화하거나 클라우드에 보관하는 기능은 아닙니다.

### 화면에 스타일이 보이지 않을 때

1. 실행 창에 `Ready`가 표시되는지 확인합니다. 창을 닫으면 서버도 중지됩니다.
2. 오래 열어 둔 미리보기 탭을 닫고 `http://localhost:3000`을 새 탭에서 엽니다. 필요하면 `Ctrl+F5`로 새로고침합니다.
3. 터미널에서 `http://localhost:3000/_next/static/css/...` 요청이 실패하거나 오류가 보이면 실행 창의 출력 내용을 확인합니다.
4. 다른 프로젝트도 3000번 포트를 사용 중이라면, BOOK NEXUS 실행 창에 표시된 실제 `Local` 주소(예: `http://localhost:3001`)를 엽니다.

## 서점 링크 등록

화면의 `서점별 내 책 확인`에서 각 서점 공식 사이트를 열어 **그 사이트에서만** 로그인합니다. 구매·보유 도서를 확인한 뒤 상품 주소를 복사하고, BOOK NEXUS로 돌아와 해당 서점 카드의 `이 서점 책 등록`을 누르면 서점이 선택된 등록 양식이 열립니다. 밀리의 서재 구독 목록은 구매 목록과 다를 수 있습니다.

1. `나의 서재`의 `+ 내 책 등록`을 누르고 `서점 링크 등록`을 선택합니다.
2. 제목·저자·서점과 해당 서점의 공식 HTTPS 상품 주소를 입력합니다.
3. `링크 저장`을 누르면 서재에 바로가기가 생깁니다. `서점 상품 보기`를 누르면 새 탭에서 해당 상품을 엽니다.

링크만 등록한 책은 BOOK NEXUS 안에서 읽거나 독서 진행률을 확인할 수 없습니다. 같은 제목의 다른 판본일 수 있으므로 주소를 직접 확인하세요. 공식 서점 도메인 외의 주소는 저장할 수 없습니다.

## 파일 등록과 읽기

1. `나의 서재`의 `+ 내 책 등록`을 누르고 `EPUB/PDF 파일 등록`을 선택합니다.
2. 보유한 DRM 없는 `.epub` 또는 `.pdf` 파일을 선택하고 제목·저자·구매처를 입력합니다. 구매처를 모르면 `직접 등록`으로 둡니다.
3. `서재에 저장`을 누른 뒤 새 책 표지를 클릭합니다. 리더에서 이전/다음, 책갈피를 사용할 수 있습니다.
4. 리더를 닫았다가 다시 열면 마지막 위치에서 시작합니다.

예시 도서 6권은 실제 서점 상품으로 연결되지만, 표시된 진행률은 데모이며 파일도 제공하지 않습니다. DRM이 걸린 서점 파일은 내장 리더에서 열 수 없습니다.

## 확인 명령

```powershell
npm.cmd run typecheck
npm.cmd run lint
npm.cmd run build
```

빌드 결과를 현재 사용자용 서재와 같은 주소에서 확인하려면 다음을 실행합니다. 먼저 기존 3021번 서버 창을 닫아야 합니다.

```powershell
npm.cmd run start -- -p 3021
```

## 폴더 구성

```text
book-nexus/
├─ app/
│  ├─ globals.css       # 반응형 스타일과 Tailwind 가져오기
│  ├─ layout.tsx        # 메타데이터 및 한국어 문서 설정
│  ├─ page.tsx          # 실재 상품 예시/내 링크/내 파일 서재와 등록 UI
│  ├─ sign-in/, sign-up/ # 로컬 로그인·회원가입 화면
│  └─ api/auth/         # BOOK NEXUS 인증 API
├─ components/
│  ├─ LocalReader.tsx   # EPUB/PDF 리더
│  └─ AuthForm.tsx      # 로그인·회원가입 양식
├─ lib/
│  ├─ local-library.ts  # 계정별 IndexedDB 링크·파일·독서 기록 저장
│  ├─ auth.ts           # 로컬 계정과 세션
│  └─ auth-client.ts    # 화면의 인증 상태
├─ scripts/setup-auth.mjs # 로컬 비밀 키·데이터 디렉터리 생성
├─ public/
│  └─ sw.js             # 배포 버전 오프라인 셸 캐시
├─ public/               # 향후 로컬 표지·아이콘 자산을 둘 위치
├─ package.json
└─ README.md
```
